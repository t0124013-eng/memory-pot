# メモリーポット（PWA版）公開手順

このフォルダの中身をそのまま無料のWeb公開サービスに置くと、生徒がスマホで開いて「ホーム画面に追加」できるアプリになります。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest | アプリ名・アイコンなどの設定 |
| sw.js | 通信なしでも開けるようにする仕組み |
| icons/ | ホーム画面のアイコン |
| vendor/xlsx.full.min.js | Excel取り込み用の部品 |
| README.md | この手順書（公開しても問題ありません） |

フォルダの構成は変えないでください。

---

## 方法A：GitHub Pages（おすすめ）

1. https://github.com で無料アカウントを作る
2. 右上の「＋」→「New repository」
   - Repository name：`swipe-anki`（英数字ならなんでも可）
   - **Public** を選ぶ（無料で公開するために必要）
   - 「Create repository」
3. 表示された画面の「uploading an existing file」をクリック
4. このフォルダの**中身をすべて**ドラッグ＆ドロップ（icons と vendor のフォルダごと）→ 下の「Commit changes」
5. 上のメニュー「Settings」→ 左の「Pages」
   - Source：「Deploy from a branch」
   - Branch：`main`、フォルダ：`/ (root)` →「Save」
6. 1〜3分待つと、同じ画面に公開URLが出ます
   `https://（ユーザー名）.github.io/swipe-anki/`

## 方法B：Cloudflare Pages

1. https://dash.cloudflare.com で無料アカウントを作る
2. 「Workers & Pages」→「作成」→「Pages」→「アセットをアップロード」
3. プロジェクト名を入力（例：`swipe-anki`）
4. このフォルダをドラッグ＆ドロップ →「デプロイ」
5. `https://swipe-anki.pages.dev` のようなURLで公開されます

## 生徒への配り方

1. 公開URLをQRコードにして配る
2. 生徒はスマホで開き、ホーム画面に追加する
   - iPhone：Safariで開く → 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
   - Android：Chromeで開く → 画面の「アプリとしてインストール」または メニュー（︙）→「ホーム画面に追加」
3. 一度開けば、そのあとは通信なしでも使えます

アプリのTOP画面の下にも、同じ手順の案内が出ます（ホーム画面から開いたときは出ません）。

## アプリを更新するとき

1. 新しい `index.html` を上書きでアップロード
2. `sw.js` の1行目近くにある `const VERSION = 'v1';` を `'v2'` のように1つ上げてアップロード

生徒側は、通信できる状態でアプリを開くと新しい版に切り替わります。

## 知っておいてほしいこと

- 学習記録・学びの木・取り込んだ単語帳は、**生徒それぞれの端末の中だけ**に保存されます。機種変更・ブラウザのデータ消去・アプリの削除で消えます。
- iPhoneでは、ホーム画面に追加したアプリと、Safariで開いたページの記録は別々になります。ホーム画面から使うように伝えてください。
- 先生が取り込んだ単語帳は生徒には届きません。全員に配りたい単語帳は、アプリ本体に収録してください。
- GitHub Pages の Public リポジトリは、中身（このフォルダ）を誰でも見られます。個人情報は入っていないので問題ありません。
